## Using Artisto 2026

Launch the application after installation, then open an existing project or create one from scratch. One possible sequence is:

1. Create artwork or bring existing artwork into the project.
2. Place supporting images and visual material on the reference board.
3. Arrange the composition using layers.
4. Tune drawing behavior through the custom brush engine.
5. Generate a palette when you need a consistent group of colors.
6. Inspect recent changes with the undo history viewer.
7. Use batch export for projects that require several output files.

During editing, hotkeys help reduce repeated navigation and keep commonly used actions accessible.
